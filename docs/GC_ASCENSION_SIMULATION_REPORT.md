Analysis `ascension-analysis/1`, simulator `player-journey/1` / `asc-model/1`, code `9a507db42c`.  Generated by `scripts/ascension_analysis.py`; **no game value, formula or save game is changed.**

Everything below runs the canonical owners (`nodebuster.ascend_mine`, `purchase_skill`, `EffectResolver`, production formula, Buildings queue rules) in a throw-away sandbox.  Policy v2 (payback-ranked purchases) for every arm; same costs, queue depth and action windows.  **The baseline contains the outpost-XP defect fixed in PR #556 (not integrated); section 9 measures its influence.**
